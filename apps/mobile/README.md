# BermudezTechOS — app móvil y web

App Expo (React Native) para Android y web. Instrucciones de arranque y comandos en el
[README principal](../../README.md#primeros-pasos); especificación y validación en
[`specs/001-finance-ui-mockup/`](../../specs/001-finance-ui-mockup/).

- Rutas (Expo Router): `src/app/`
- Tema y tokens: `src/theme/`
- Componentes base: `src/components/ui/`
- Módulos y menú: `src/modules/registry.ts`
- Finanzas: `src/modules/finance/` (`domain/` cálculos puros, `data/` repositorio en memoria y seed, `hooks/`, `components/`)
